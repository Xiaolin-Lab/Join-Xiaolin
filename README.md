## 👋 Welcome to Xiaolin Lab

**Xiaolin Lab** 是一个面向开发者、学生、独立开发者和创作者的开放社区。

我们希望给每一个正在创造东西的人一个展示自己的地方。

无论你正在：

- 🌐 搭建自己的个人网站
- 🚀 开发自己的项目或产品
- 🤖 探索 AI 与智能体
- 💻 学习编程与软件开发
- 🎨 进行 UI / UX 与创意设计
- 🌱 刚刚开始自己的开发者旅程

都欢迎来到 **Xiaolin Lab**。

## 🚀 How to Join

加入 Xiaolin Lab 非常简单：

### 01 · Submit your application

点击下面的按钮提交 **Join Request**。

### 02 · Introduce yourself

告诉我们你的 GitHub、个人网站、作品以及你感兴趣的方向。

### 03 · Application review

我们会查看你的申请与相关作品。

### 04 · Join the community

通过后，你将收到加入 **Xiaolin Lab GitHub Organization** 的邀请。
